OLD VS NEW 2

Hey! This is Old vs New² (OVN2), a HUD that takes inspiration from various points on the tf2 life, like a centered hud, a custom font,side hud if you like it or a more normal mode for being classic(minmode!),Sudo minimalitic health and ammo,a recreation of the 2010 menu, the full screen matchmaking menus from 2016, the reintroducion of quickplay thanks to mastercomfig with addition of the old teamworks.tf quickplay,and the addition of some community servers manage by other community members! you know the good stuff

IMPORTANT!
Everytime that you change resolutions to/from 4:3 make sure to use the "Menu Reload" button in the extras menu
If you dont like the in-game hud/the custom main menu you can delete the menu related files/in-game related files 
If there is a bug I miss out or a feauture that could be added leave it the comments section of gamebanana or my steam profile!
I planned this hud for 16:10 and 4:3, there might unintended placement in other resolutions but this dont affect gameplay

INSTALLATION!

Extract on the .rar file in YourDisk:\SteamLibrary\steamapps\common\Team Fortress 2\tf\custom
Run TF2
If buttons doesn't work for any reason type toggle mat_aaquality or click the "menu reload" button in the extras menu
(the button thats far right)
And you should be good to go!
